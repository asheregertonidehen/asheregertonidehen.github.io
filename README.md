# Asher Egerton-Idehen — Personal Site

A minimal, dependency-free personal site designed for GitHub Pages.

## Publish with GitHub Pages

1. Push this repository to GitHub.
2. Open **Settings → Pages** in the repository.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select the `main` branch and `/ (root)`, then save.

The social, paper, and dataset destinations in `index.html` are placeholders and can be replaced directly when the final URLs are available.
